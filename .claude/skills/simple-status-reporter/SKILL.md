# Simple Status Reporter

After each step, report in this exact format:

## Planned

What was supposed to be done.

## Done

What was actually created or changed.

## Files Produced

List files.

## Validation

List commands and pass/fail.

## Current System State

Say which block is complete.

## Output Meaning

Explain what the output means in simple language.

## Next Step

State the next safe command or block.

## Stop

Do not continue automatically.
Wait for user approval.
